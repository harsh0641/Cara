# Cara — E-Commerce Website

A responsive, multi-page e-commerce storefront built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies — pure frontend.

🌐 **Live Demo:** [harsh0641.github.io/Cara](https://harsh0641.github.io/Cara/)

---

## Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Hero banner, featured products, promotions |
| Shop | `shop.html` | Full product grid with category layout |
| Product | `sproduct.html` | Single product detail view |
| Cart | `card.html` | Shopping cart with item management |
| Blog | `blog.html` | Blog listing page |
| About | `about.html` | Brand story and team section |
| Contact | `contact.html` | Contact form |

---

## Features

- Fully responsive layout — mobile, tablet, and desktop
- Multi-page navigation with consistent header and footer
- Product grid with hover effects
- Shopping cart UI
- Clean, modern design with custom CSS styling

---

## Tech Stack

`HTML5` `CSS3` `JavaScript`

---

## Getting Started

No installation needed. Clone and open directly in browser:

```bash
git clone https://github.com/harsh0641/Cara.git
cd Cara
# Open index.html in your browser
```
